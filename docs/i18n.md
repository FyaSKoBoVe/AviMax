# Internationalization (i18n) Guide

## Overview

CutFlow supports internationalization using Qt's translation system. Translation files are located in `cutflow/i18n/`.

## Translation Files

### Source Files (.ts)
- `cutflow_en.ts` - English (source language)
- `cutflow_it.ts` - Italian

### Compiled Files (.qm)
Compiled translation files (.qm) are generated from .ts files using Qt's `lrelease` tool.

## Adding Translations

### 1. Add Translatable Strings in Code

Use `self.tr()` or `QCoreApplication.translate()` for translatable strings:

```python
from PySide6.QtCore import QCoreApplication

# In a class method
self.tr("File")  # Uses class name as context

# Or with explicit context
QCoreApplication.translate("MainWindow", "File")
```

### 2. Update Translation Files

Extract new strings from code using `pyside6-lupdate`:

```bash
pyside6-lupdate cutflow/ -ts cutflow/i18n/catflow_en.ts cutflow/i18n/cutflow_it.ts
```

### 3. Edit Translation Files

Edit the .ts files manually or use Qt Linguist:

```bash
linguist cutflow/i18n/cutflow_it.ts
```

### 4. Compile Translations

Generate .qm files from .ts files:

```bash
lrelease cutflow/i18n/cutflow_en.ts -qm cutflow/i18n/cutflow_en.qm
lrelease cutflow/i18n/cutflow_it.ts -qm cutflow/i18n/cutflow_it.qm
```

## Loading Translations

The `Translator` class in `cutflow/i18n/translator.py` handles loading translations:

```python
translator = Translator()
translator.load_translations(app)
```

Translations are loaded based on system locale. If no matching translation is found, English is used as fallback.

## Adding a New Language

1. Create a new .ts file for the language:

```bash
pyside6-lupdate cutflow/ -ts cutflow/i18n/cutflow_de.ts  # German
```

2. Translate the strings in the .ts file

3. Compile to .qm:

```bash
lrelease cutflow/i18n/cutflow_de.ts -qm cutflow/i18n/cutflow_de.qm
```

4. The translator will automatically load it if the system locale matches

## Translation Contexts

Translations are organized by context (class name):

- `MainWindow` - Main window UI elements
- `PlayerWidget` - Player controls
- `TimelineWidget` - Timeline controls
- `MetadataPanel` - Metadata display
- `FilterPanel` - Filter controls
- `ExportPanel` - Export settings
- `ExportDialog` - Export dialog
- `ExportQueue` - Export queue UI

## Best Practices

1. **Use descriptive context names** - Group related strings by class/component
2. **Keep strings short** - UI elements should be concise
3. **Avoid concatenation** - Use complete sentences instead of building them from parts
4. **Provide context comments** - Add comments in .ts files for translators
5. **Test translations** - Verify UI layout with different languages (some languages are longer)
