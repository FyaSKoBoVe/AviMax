# UX Personas for CutFlow

## Persona 1: Marco - Content Creator

**Demographics**
- Age: 28
- Occupation: YouTuber/TikTok Creator
- Technical Skill: Intermediate
- Platform: Windows/macOS

**Goals**
- Quickly edit gameplay footage for YouTube
- Create vertical videos for TikTok/Instagram
- Export with optimal settings for each platform
- Maintain high quality with fast processing

**Pain Points**
- Complex video editors are too slow for simple cuts
- Needs to export multiple formats for different platforms
- Stream copy mode is essential for speed
- Wants to add basic filters without re-encoding

**Usage Patterns**
- Imports 4K gameplay footage
- Cuts highlights using In/Out markers
- Exports 1080p for YouTube, vertical for TikTok
- Uses stream copy for speed, reencode only when needed

## Persona 2: Giulia - Teacher

**Demographics**
- Age: 42
- Occupation: School Teacher
- Technical Skill: Beginner
- Platform: Windows

**Goals**
- Create educational videos from recorded lessons
- Trim unwanted sections from recordings
- Add simple fade effects
- Export in standard MP4 format

**Pain Points**
- Overwhelmed by complex interfaces
- Needs clear visual feedback
- Wants simple presets (no technical settings)
- Needs undo functionality for mistakes

**Usage Patterns**
- Imports Zoom/Teams recordings
- Uses timeline to find start/end points
- Applies fade in/out transitions
- Exports with "Standard MP4" preset

## Persona 3: Alessandro - Video Editor

**Demographics**
- Age: 35
- Occupation: Freelance Video Editor
- Technical Skill: Advanced
- Platform: Linux

**Goals**
- Fast cutting and merging of multiple clips
- Precise frame-accurate cuts
- Batch processing of multiple exports
- Custom codec settings for specific clients

**Pain Points**
- Needs precise control over encoding parameters
- Wants to queue multiple exports
- Requires accurate time-based cutting
- Needs to work with large files (>4GB)

**Usage Patterns**
- Uses reencode mode for frame accuracy
- Queues multiple export jobs
- Uses custom CRF and bitrate settings
- Merges multiple clips into single output

## Persona 4: Sofia - Social Media Manager

**Demographics**
- Age: 26
- Occupation: Social Media Manager
- Technical Skill: Intermediate
- Platform: macOS

**Goals**
- Repurpose content across platforms
- Create square and vertical formats
- Add captions and filters
- Quick turnaround for trending content

**Pain Points**
- Needs multiple aspect ratios
- Platform-specific export requirements
- Needs to add basic color corrections
- Batch processing for multiple videos

**Usage Patterns**

- Crops to square/vertical format
- Applies brightness/contrast filters
- Exports with platform-specific presets
